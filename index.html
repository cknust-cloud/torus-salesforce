Agentforce

Agents that act, not just answer.

Four concrete jobs Torus already does manually — each one a candidate for an agent that triggers, decides, and acts inside the same platform.

Telemetry Triage Agent

Triggers on: an anomaly signal from a Torus Station or Spin unit
Decides: severity and likely cause, from historical fault patterns
Acts: opens a case and dispatches a technician with the right part, or resolves remotely

Warranty Lifecycle Agent

Triggers on: a unit approaching a maintenance milestone inside its 25-year warranty
Decides: what maintenance or firmware action is due
Acts: schedules a visit or pushes an update, and logs it to the asset record

Utility RFP Agent

Triggers on: a utility partner issuing a capacity or demand-response RFP
Decides: which deployment specs and prior performance data match the ask
Acts: drafts a first-pass response for the deal team to refine, not send unreviewed

Residential Support Agent

Triggers on: a homeowner message about their Torus Station
Decides: FAQ, billing question, or a real fault
Acts: answers directly, or escalates to a human with full account and device history

Phase 1 · First 90 Days

Map the three businesses

Milestone: unified pipeline view live for one segment
Phase 2 · Months 3–6

Connect the physical world

Stand up Field Service for install and commissioning workflows tied to GigaOne production; connect Data 360 to device telemetry from deployed units.

Milestone: first automated telemetry-to-case flow live
Phase 3 · Months 6–12

Turn on the agents

Launch the Telemetry Triage, Warranty Lifecycle, and Utility RFP agents; extend Slack as the shared surface for sales, service, and grid alerts.
